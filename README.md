# Automata.ai — Static Site

This is a pure static React + Vite + Tailwind site. No backend, no API, no Express, no server — just static files for deployment on Vercel, Netlify, or any static host.

## Local Development
```sh
cd client
npm install
npm run dev
```

## Production Build
```sh
cd client
npm run build
```
The static site will be in `client/dist`.

## Deploying to Vercel
- Set project root to `client`
- Build command: `npm run build`
- Output directory: `dist`

---
All backend/server code has been removed. This repo is now frontend-only.
